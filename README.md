# Second-Smallest-Element-In-an-Array
A simple C++ program that provide the second smallest element of an array entered by the user
The program:
- Takes the size of the array as input.
- Accepts array elements from the user.
- Sorts the array in ascending order.
- Displays the sorted array.
- Finds and prints the second smallest distinct element.

## Algorithm
1. Read the size of the array.
2. Input all array elements.
3. Sort the array using sort().
4. Traverse the sorted array.
5. Find the first element that is greater than the smallest element.
6. Print it as the second smallest element.

## Concepts Used
- Arrays
- User Input/Output
- sort() function from the C++ Standard Library
- Loops
- Conditional Statements
